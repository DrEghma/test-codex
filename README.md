# Overtime Logger (ثبت اضافه کاری)

این یک برنامه ساده کنسولی برای ثبت اضافه‌کاری در ویندوز است. اطلاعات در فایل JSON ذخیره می‌شود و امکان خروجی CSV نیز وجود دارد.

## اجرا

نیاز به .NET 6 SDK دارید.

```bash
dotnet run --project OvertimeLogger
```

## امکانات

- ثبت رکوردهای اضافه‌کاری (تاریخ، ساعت، توضیح)
- مشاهده همه رکوردها
- خلاصه ماهانه ساعات اضافه‌کاری
- خروجی گرفتن فایل CSV
